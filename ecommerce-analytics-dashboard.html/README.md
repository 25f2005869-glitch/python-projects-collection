A responsive dashboard concept for exploring e-commerce sales, product revenue, regional performance, and customer segments in one place.

## Project Overview

This project brings key e-commerce metrics into a single visual dashboard. It includes summary figures, monthly revenue, category and regional breakdowns, top products, and customer segments.

The project was created as part of my learning journey in data science and data analytics.

## Dashboard Features

- Key metrics for revenue, orders, customers, products sold, average order value, and returning customers
- Monthly revenue chart
- Revenue breakdown by product category
- Revenue by region
- Top products ranked by revenue
- Customer segment counts
- New versus returning customer breakdown
- Year and date range controls
- Responsive layout for desktop and mobile screens
- Indian Rupee formatting

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `ecommerce-analytics-dashboard.html` in a web browser.
3. Use the year selector and date fields to change the reporting period.

No installation or additional libraries are required.
